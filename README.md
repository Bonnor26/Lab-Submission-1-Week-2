# Lab Submission 1 Week 2

Chess Game — Unity Editor Scripting Lab

I did this on my own (Connor Hewitt)

## What This Does
- Draws an 8x8 chess board using Gizmos
- Places a full white piece set (pawn, rook, knight, bishop, queen, king), each with editable piece type and color tint via the Inspector
- Selecting a piece shows its possible movement squares via Gizmos
- A custom Editor script (ChessPieceEditor.cs) adds an interactive Handle border around the selected piece; moving it snaps to the nearest board square instead of allowing free placement
